## คำถามที่ต้องได้คำตอบจากฝ่ายบัญชีก่อนเปิดใช้ Budget.js

1. PC กลาง (ตารางที่สอง) จะตัดงบจากไหน — ให้ผู้เบิกเลือกโปรเจกต์ตอนยืนยัน / แบ่งสัดส่วนตามการเบิกที่ผ่านมา / ตั้งงบกลางแยกต่างหาก
2. เมื่อ PC ตรงกับหลายบริษัท/หลายตัวแปร (เช่น Metro Poster, SBS, Flyover 2.0) จะรวมงบทุกบริษัทหรือแยก
3. ใช้ GL Code ไหนเทียบเป็นค่าเริ่มต้น — 530090 (ค่าวัสดุสิ้นเปลืองใช้ไป) หรือ 530050 (ค่าซ่อมแซมบำรุงรักษาป้ายโฆษณา) หรือกำหนดต่อ PC
4. เช็คงบตามรายเดือน หรือดูยอดคงเหลือสะสมทั้งปี (ไฟล์ที่ได้รับมีเฉพาะ Revise Budget ช่วง ก.ค.–ธ.ค.)
5. ไฟล์ Budget ไม่มียอดใช้จริง (actual) ระบบจะถือว่า `pr_po_log` (ที่แอปนี้เขียนเองทุกครั้งที่ออก PR/PO) คือยอดที่ตัดไปแล้ว ยอดคงเหลือ = งบ - ผลรวมใน pr_po_log ยืนยันว่าฝ่ายบัญชีตกลงด้วยกับวิธีนี้ไหม หรือมีระบบอื่นที่ตัดงบอยู่แล้วที่ควรไปดึงยอดจริงมาแทน

เมื่อได้คำตอบครบ ให้กรอกลง Sheet `master_pc` (คอลัมน์: pc_code, pc_name, owner_email, manager_email, budget_location, budget_gl_code) แล้ว `Budget.js.checkBudget_()` จะพร้อมใช้งานจริง
